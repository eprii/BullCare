# Perbaikan BullCare V3

Perubahan pada versi ini:

1. Menghilangkan overflow pada kartu daftar bull dengan mengubah susunan status dan ikon navigasi menjadi horizontal.
2. Menambahkan halaman `ActivityDetailPage` yang menampilkan jenis aktivitas, data bull, seluruh pekerjaan yang dicatat, petugas, tanggal, dan metadata pencatatan.
3. Membuat item aktivitas pada Dashboard, menu Aktivitas, dan Riwayat Profil Bull dapat dibuka menuju halaman detail.
4. Menambahkan mekanisme pemberitahuan perubahan data dari menu Bull dan Aktivitas ke Dashboard.
5. Dashboard memuat ulang data saat bull atau aktivitas ditambah, diedit, atau dihapus, serta setiap kali tab Dashboard dibuka kembali.
6. Membatasi teks ringkasan aktivitas agar tidak menyebabkan overflow pada kartu aktivitas.
