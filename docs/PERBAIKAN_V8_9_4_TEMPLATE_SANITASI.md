# BullCare V8.9.4 - Template Laporan Sanitasi

Perubahan ini hanya memengaruhi hasil export PDF/Word untuk sumber data sanitasi.

- Sanitasi Kandang, Sanitasi Tempat Makan, dan Sanitasi Pejantan memakai template khusus yang mengikuti struktur FORMULIR SANITASI KANDANG DAN PEJANTAN SOP-6.3.l.
- Header memuat identitas Balai Inseminasi Buatan Provinsi Kalimantan Selatan, nomor dokumen, revisi, tanggal berlaku, halaman, logo, dan judul formulir.
- Data disusun sebagai matriks tanggal 1-31 x bull, dilengkapi Keterangan dan Paraf Petugas.
- Tanda X menunjukkan aktivitas sanitasi tercatat untuk bull pada tanggal tersebut.
- Sanitasi Kandang dan Tempat Makan menampilkan waktu pelaksanaan SETIAP HARI; Sanitasi Pejantan SETIAP BULAN mengikuti sistem BullCare saat ini.
- Jika periode mencakup beberapa bulan, setiap bulan dibuat lembar tersendiri.
- Maksimal 30 bull per lembar; apabila bull lebih banyak, lembar otomatis dilanjutkan.
- Aktivitas non-sanitasi tetap memakai template laporan BullCare sebelumnya.
